Plan the task-priority feature.

Agreed requirements:
- Priorities are High, Medium, and Low.
- New tasks default to Medium.
- Existing saved tasks without priority are treated as Medium.
- Open tasks are sorted High, Medium, then Low.
- Tasks with the same priority keep creation order.
- Completed tasks are excluded from the summary.
- Users can filter open tasks by priority.
- No frameworks, packages, or CDN dependencies.

Excluded scope:
- No editing priority after task creation.
- No backend, database, user accounts, due dates, or drag-and-drop.

Include:
1. Files to change
2. Data-model changes
3. UI changes
4. localStorage compatibility
5. Manual verification scenarios
6. Risks and assumptions
